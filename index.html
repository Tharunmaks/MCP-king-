Rules files and skills

      
Rules files shape every answer. Skills (SKILL.md) teach the AI a whole workflow and load only when needed, so they cost almost nothing until used.

    

    

      
      
    

    

    

      

        
Install every skill at once (Claude Code, PC or Termux):

        
git clone https://github.com/Tharunmaks/MCP-king- ~/MCP-king-
mkdir -p ~/.claude/skills && cp -r ~/MCP-king-/skills/* ~/.claude/skills/

        
        
Claude apps (web, desktop, phone): Settings → Capabilities → Skills → upload a skill folder as a .zip. Other AIs: paste the skill text into the chat or your rules file.
